Конструктор TaskBehaviour

Соберите настройку для списка TaskBehaviour (Behaviour, StylingResultButton, StylingActions) и сразу посмотрите, что увидит пользователь в карточке задачи. Страница автономная: ничего не отправляет и не требует приложения — просто откройте файл в браузере.

1. Behaviour — что происходит при нажатии результата

Ключи: loc — диалог «Где найдена ЕО?», dlg — диалог закрытия по типу контента (по колонкам), p — поля ввода, ic — две кнопки, c — подтверждение, aa/aar — доп. действия и их обязательность, anim — анимация.

Поля заявки (rf) в шапке карточки

Результаты

2. StylingResultButton — цвета и иконки кнопок результата

bg — фон (градиент или цвет), c — цвет текста, v — вариант (ctd заливка / out контур / tx текст), i — иконка.

3. StylingActions — кнопки действий и формы

takeInWork — «Взять в работу», confirm/cancel — подтверждение (ic и диалоги), promptSubmit/promptCancel — кнопки формы ввода полей.

Предпросмотр карточки

Нажмите кнопку результата — увидите ровно тот поток, который задаёт конфигурация слева.

Шпаргалка

КлючЧто делает
dlgзакрыть задачу через диалог по типу контента: форма собирается по колонкам SharePoint (rich-текст, автокомплиты, «Пользователь или группа», числа), обязательность — из Required колонок. Приоритетнее loc/p/aa/ic. Тип «Результат проверки ООБ» получает такой диалог автоматически, без записи в TaskBehaviour
